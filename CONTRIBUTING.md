# Contributing

Thanks for wanting to make the diary better.

1. **Small fixes** (a typo, a broken install line, a bug with a clear fix): open a pull request directly.
2. **Anything bigger** (a new effect, a new sound, a change to how the page looks): open an issue first and describe it. Wait for a yes before building it, so your time is not wasted.

Before you open a pull request, run these from the repo root:

```sh
claude plugin validate .
claude plugin test .
```

Both must pass. A change to how the page looks needs a screenshot from the Claude desktop app, in light and dark mode.

**Keep it original.** Every picture, word and sound in Horcrux is our own. Please do not add film stills, logos, crests, fonts from the films, lines quoted from the books or films, or their music. Draw it, write it or make the sound yourself.
